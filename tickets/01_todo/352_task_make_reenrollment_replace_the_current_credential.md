# Task: Make re-enrollment replace the current credential

Parent: `350_story_single_credential_reenrollment_and_immediate_effect.md`

## Scope

Teach enrollment/re-enrollment to replace the credential for the same logical instance instead of creating a rotation subsystem.

## Acceptance criteria

- [ ] Re-enrollment can target the same logical instance.
- [ ] Issuing the new credential replaces the previous one.
- [ ] Old credentials are not kept as a product feature/history surface.
