# RF-0031 — Pair resource controls lack their intended programmatic labels

**Priority:** Low · **State:** open

**Review aliases:** `W-06` · **Confidence:** High for static label/ID wiring; no accessibility-tree or screen-reader execution.

## Why it matters

The Create pair resource selector and new-resource input are not associated with their intended descriptive labels, reducing context for assistive-technology users.

## Suggested fix

Associate meaningful labels with the actual controls in both existing-resource and new-resource modes.

## Decision and caveat

Open, Low-priority accessibility defect; preserve the current mode choice and validation behavior.
This is a static component-wiring finding, not an application-wide accessibility or WCAG audit.
A placeholder is not the intended label association.

No correction is authorized or completed by this record.
