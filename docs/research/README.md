# Research

`docs/research/` holds dated investigations that preserve evidence, rejected options, assumptions, and visible retractions.

Use names such as `YYYY-MM-DD_<topic>.md`.

Do not silently rewrite an earlier conclusion when later evidence overturns it.

State the retraction, the evidence that caused it, and the resulting decision or open question.

Research informs a plan or ADR but does not authorize implementation by itself.
