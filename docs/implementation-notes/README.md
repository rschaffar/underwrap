# Implementation notes

`docs/implementation-notes/` holds maintained descriptions of current internal mechanisms and empirical findings.

Write notes in present tense and keep them aligned with code, tested configuration, and current security documentation.

Record commands, environments, versions, and limits when they affect the result.

Move durable facts out of completed plans before archiving them.

Do not use this directory for unverified speculation, superseded product behavior, or active task checklists.
